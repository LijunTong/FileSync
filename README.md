# FileSync - 文件同步备份工具

一个现代化的 Windows 文件同步备份工具，支持多任务管理、定时调度、增量更新和双向同步。

---

## ✨ 功能特性

| 功能 | 描述 |
|------|------|
| 📋 **多任务管理** | 创建和管理多个同步任务，独立配置 |
| 🔄 **同步模式** | 支持双向同步、增量更新、备份模式 |
| 🕐 **调度系统** | 手动、每分钟、每小时、每天、每周、Cron 表达式 |
| 🔍 **文件冲突检测** | 智能识别文件变更，避免误操作 |
| 📊 **运行日志** | 完整的同步历史和文件操作记录 |
| 🎨 **主题切换** | 支持深色/浅色主题 |
| 📥 **系统托盘** | 最小化到托盘，后台运行 |
| 🔒 **单实例限制** | 确保只运行一个实例 |

## 🚀 安装和使用

### 系统要求
- Windows 7 SP1 或更高版本
- .NET Framework 4.7.2

### 安装方式

#### 方式一：发布包安装（推荐）
1. 从 GitHub Releases 下载 `FileSync-Release.zip`
2. 解压到任意目录
3. 运行 `FileSync.exe`

#### 方式二：源码编译
1. 克隆或下载项目源码
2. 使用 Visual Studio 2022 打开 `FileSync.sln`
3. 选择 `Release` 配置并构建
4. 运行 `FileSync\bin\Release\FileSync.exe`

## 📖 使用指南

### 1. 创建同步任务

点击主界面的 **"+ 新建任务"** 按钮，填写：
- **任务名称**：唯一标识，例如"工作文档同步"
- **源目录**：要同步的源文件夹
- **目标目录**：同步目标文件夹
- **同步模式**：
  - **双向同步**：源和目标保持一致，互相更新
  - **增量更新**：只将源新增/修改的文件复制到目标
  - **备份模式**：完整复制源到目标，目标删除时提示

### 2. 配置调度

| 调度类型 | 说明 |
|----------|------|
| 手动执行 | 仅手动点击立即同步运行 |
| 每隔 N 分钟 | 指定间隔循环运行 |
| 每小时 | 每个小时的固定分钟运行 |
| 每天 | 指定时间每日运行 |
| 每周 | 指定星期几和时间运行 |
| Cron 表达式 | 灵活自定义调度 |

### 3. 查看日志

- 点击任务右侧的 "📋" 按钮查看该任务同步历史
- 查看同步状态、文件操作详情、错误信息
